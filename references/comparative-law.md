# 比较法协议

比较法服务于中国法问题，不是显示资料数量或“国际视野”的装饰。

## 〇、三种属性与五项功能

比较法在后发法域的法律评注中有三重属性：

1. **母法**：中国民法主要继受德、日及民国—台湾地区“民法”，条文模糊时可回母法查明制度构造；
2. **共同法**：私法规则具有相似性，可用于对比、批判，避免法学封闭；
3. **法学资料库**：域外立法例、学说与判例是现成智识，可降低重复摸索成本。

由此产生五项可用功能：阐明法条本义、发现法律漏洞、启发或证成法律续造、提示评注盲点（拓展问题清单）、强化说理论证并提供分析路径。

这同时解释了为何不能照搬德国评注“冷落比较法”的做法：德国法学居于输出地位，中国法是后发法、继受法与混合继受法。但“需要比较法”不等于“比较法越多越好”——是否使用由功能触发，不由数量指标决定。

## 一、启动条件

只有至少满足一项时才启动实质比较：

- 中国条款存在可查明的继受、移植或共同文本来源；
- 国内解释出现难以单靠本国材料解决的制度功能冲突；
- 外国法提供可比较的替代制度设计或成熟案例类型；
- 用户或目标期刊明确要求，并且能够取得原始材料。

不满足时，可以在检索日志记录“评估后未采用比较法”，不必强行加入章节。

## 一之一、继受链核查

使用母法前先查清继受路径，至少回答：

- 本条的直接母法是谁（德、日、瑞士、苏联、英美法或国际条约）；
- 是否存在转继受（如中国—日本—德国、民国—德国/瑞士），转继受中是否发生变形；
- 我国条文是单一继受还是混合继受；混合继受时，不同来源的制度是否已被本土体系重新组合；
- 母法国后来的修法或判例转向，是否影响其作为解释参考的价值。

不得把“某国如此”直接等同于“母法如此”，也不得把转继受链条中的中间法当作母法。

## 一之二、四项限度

1. **必要性**：不借助比较法也能达到同样论证效果时，不使用；国内研究已足够时引国内文献即可。
2. **融贯性**：优先选择与我国民法概念体系、制度构成、法学原理相通的法域；即使某制度参考了英美法或国际条约，也须说明其如何融入中国民法典的概念体系。
3. **符合性**：结合中国社会经济实际与本土文化判断制度效果。条文相似不等于实践相同（如同一规则在德、日、台湾地区的裁判立场可能分化）；不得把外国实践差异简单判为对错。
4. **自主性**：比较法只用于提升中国评注质量，不得把中国评注变成外国评注的译本；以现行法为基础、整体法秩序为界限、本土学说为经、本土判决为纬。

## 二、法域选择备忘录

在正文写作前，记录：

1. 为何选择该法域而非其他法域；
2. 比较对象是同名制度、共同功能、继受母法还是问题解决机制；
3. 比较的时间截面和法源范围；
4. 与中国法在宪法结构、法院体系、程序、市场与社会事实上的重要差异；
5. 预期用途：解释来源、评价、模型构建、反例或制度建议。

仅因资料易得或作者熟悉某语言，不足以证明代表性，但可以作为研究限制如实说明。

上述内容固定写入 `11-comparative-memo.md`；未启用比较法时也在该文件说明不适用的理由。启用后必须同时完成法域选择理由、原始法源与制度语境、功能比较、可移植性分级和反向校验，不能只在正文临时插入外国材料。

## 三、原始材料链

每个法域至少努力覆盖：现行法规官方文本、关键判例原文、立法材料、权威评注/专著和最新学术研究。先用二手文献发现术语和代表来源，再回原典。

记录本地语原词、正式法条号、案件中立引注/报告引注、版本日期与访问日期。机器翻译只作为阅读辅助；决定结论的术语须对照原文，必要时保留原词。

## 四、内在理解与功能比较

先从外国法自身语境解释：法源层级、制度位置、案件事实、程序姿态和学说争议。随后再做功能比较：两国制度解决的实际问题是否同一，产生该问题的规范与社会条件是否可比。

避免以下等号：相同中文译名 = 相同制度；相似条文 = 相同解释；最高法院一句话 = 整个法域通说；欧盟法 = 成员国实施法；美国联邦法 = 各州法。

## 五、可移植性矩阵

对拟借鉴方案逐项评价：

| 维度 | 问题 |
| --- | --- |
| 文本兼容 | 中国条文文义是否容纳，还是需要修法？ |
| 体系兼容 | 与相邻制度、特别法和请求权体系是否冲突？ |
| 权限兼容 | 法院能否通过解释采用，还是属于立法选择？ |
| 程序兼容 | 证明、救济、审级和先例机制是否支持？ |
| 事实兼容 | 市场结构、技术条件和行为激励是否相近？ |
| 价值兼容 | 保护利益和风险分配是否符合中国法秩序？ |
| 可执行性 | 裁判者能否用清晰要件和证据操作？ |

正文结论应使用“可解释吸收”“仅提供反例”“需制度改造”“不宜移植”等分级表达，避免笼统“借鉴”。

## 六、反向校验

完成比较法章节后再问：删掉外国法部分，中国法论证是否完全不受影响？若是，比较法很可能只是陈列。外国方案是否被理想化，而国内制度只列缺点？是否主动检索了外国法的批评、例外和实施失败？

无法取得原文或无法读懂关键语言时，缩小主张并标注转引，不得把聚合 MCP 的摘要直接写成外国现行法结论。

若论证思路实际取自比较法，应在脚注标明来源，不得“策略性舍弃”以制造原创印象；隐性移植与伪造引注同属学术不端。
