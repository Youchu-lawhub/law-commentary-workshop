# 引注与出处控制

本文件以通行法学引注规范为默认基线。目标期刊的现行投稿须知、编辑部样例或指定引注体例有不同规定时，从其规定，并在 `research-profile.yaml` 记录版本和核验日。

## 一、先判断能否引用

引注应真实、相关、权威、准确、完整并保持适度。每条脚注须回答至少一个问题：原文在哪里、谁提出该观点、规范依据为何、案例如何支持、或反方依据是什么。

只有 `primary_verified` 的规范/案例、`fulltext_read` 的学术文献，以及精确限定于所读范围的 `partial_read` 文献可作为成稿实质依据。`partial_read` 不得被概括为作者全文立场；`abstract_read` 只能在明确说明仅据摘要时有限使用；`metadata_verified` 只证明文献存在。

直接引文加引号，逐字核对并给精确页码、边码、条号或段落。概括引文不加引号，但仍给定位且不得改变限定条件。无法取得原文时使用“转引自”，同时列出原初文献和实际查阅的二手来源。

## 二、默认中文格式

以下是字段骨架，不可把示例字段原样留在成稿。

- 专著：`作者：《书名》，出版社年份版，第X页。`
- 译著：`[国别]作者：《书名》，译者译，出版社年份版，第X页。`
- 期刊论文：`作者：《文章名》，载《期刊名》年份第X期，第X页。`
- 文集论文：`作者：《文章名》，载编者主编：《文集名》，出版社年份版，第X页。`
- 学位论文：`作者：《题名》，学校年份博士/硕士学位论文，第X页。`
- 报纸：`作者：《文章名》，载《报纸名》YYYY年M月D日，第X版。`
- 网络文献：`作者：《文章名》，载网站名YYYY年M月D日，URL。` 页面无上传日或为动态结果时，在 URL 后写 `YYYY年M月D日访问`；一般稳定页面无需机械添加访问日。

图书信息以版权页为准，论文信息以论文首页为准。已有正式纸质版本时，原则上引正式版本；最初刊发版本通常优先于转载。页码必须是实际支持命题的位置，而非文章起止页。

不要自动套用 GB/T 7714，也不要一律删除 DOI。是否使用文后参考文献、文献类型标识、DOI 或 URL 由目标期刊规则决定。中文法学期刊通常以脚注为主，但必须核实具体期刊。

## 三、法律文件

- 法律名称加书名号；不致误解时可省略“中华人民共和国”。
- 一般法律条文：`《民法典》第XXX条第X款第X项。`
- 条、款、项、目序数使用阿拉伯数字；“之一”等保留汉字；文件名称内部的条号从原文。
- 经过修改的法律，若上下文不能确定版本，写 `《公司法》（2023年修订）第X条` 等版本信息。
- 失效规范明确标“已失效/已废止”；草案标明审议阶段和日期。
- 规范性文件一般列制定机关、全名与文号；文号年份按目标体例统一，不自行省略。

正文大段引用法条会削弱分析，除非逐句解释确有必要。凡直接引法条，应与官方文本逐字对照，连同款项和但书一起校核。

## 四、中国案例

普通裁判文书基本字段：正文未提及时的案例名称、法院全称、案号、文书类型；裁判日期在涉及时间、案号年份不同或期刊要求时标明。

格式骨架：

- `甲诉乙……案，XX人民法院（YYYY）X法X字X号民事判决书。`
- 指导性案例：`案例名称，最高人民法院指导性案例X号（YYYY年）。`
- 人民法院案例库：`案例名称，人民法院案例库入库编号。`
- 公报案例：`案例名称，载《最高人民法院公报》YYYY年第X期。`

案号从原文抄录；2016年后案号通常不带“字”“第”，法院代码开头的 0 不可随意省略。隐名遵循官方案例文本和目标期刊伦理要求。

脚注格式完整不证明案例真实。引用裁判理由前，证据账本必须有对应 `source_id`、原文定位和后续状态；指导性案例被宣布不再参照、案例文本调整或法律基础变化时，应在正文或脚注说明。

## 五、再次引用与多文献

初次引用给完整信息；内容定稿前不建议大量使用“同前注”“同上注”，避免重排后错乱。需要略写时，按目标期刊规则写作者、简称、首次注号与当前页码。

同一脚注的同类文献通常按时间排列，用分号分隔。不要为制造“引注墙”堆入无关来源；同一脚注一般控制在最能支持命题的少量文献，确需呈现学说谱系时可扩大并说明功能。

## 六、外文来源

尊重法域自身引注习惯和通行引注规范的对应语种规则：

- 英国法规使用法定简称、年份和条款；案例优先官方报告或中立引注并给页/段落；
- 美国联邦法律按 Statutes at Large 或 U.S.C.；案例含案名、卷号、报告集、首页、法院/年份及精确页；
- 欧盟法规列文件类型、编号与条款，必要时加 OJ 或 EUR-Lex；
- 德文专著/评注区分页码 `S.` 与边码 `Rn.`；法律常用 `§/Art.`，案例依判例集/期刊格式。

不要把搜索引擎生成的“标准引用”直接采用。以官方文本、报告集、数据库导出和原文首页交叉核对。

## 七、脚注与证据审计

`08-citation-audit.csv` 建议字段：

```text
note_id,draft_location,claim_id,source_ids,citation_text,quote_or_paraphrase,citation_mode,pinpoint_checked,metadata_checked,source_status,issues,resolved
```

一个脚注支持多个命题或来源时，`claim_id`、`source_ids` 均使用分号分隔。`citation_mode` 使用 `direct_source` 或 `secondary_citation`。未读取外国官方原文而经中文/外文学术来源介绍外国法时，只能用 `secondary_citation`，脚注写明“转引自”，并同时记录实际阅读的二手来源；不得把二手材料伪装成对外国法现状的直接核验。

逐注检查：正文命题是否与来源一致；是否给精确定位；引文与原文是否逐字一致；作者观点是否被正确归属；转引是否诚实；版本、案号和链接是否可用；同一来源格式是否统一。

文后参考文献若存在，原则上只列正文实际引注的来源，并与脚注双向核对。孤立参考文献、无定义脚注和无正文引用的脚注都应清理。
