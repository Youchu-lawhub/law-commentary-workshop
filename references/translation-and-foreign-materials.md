# 外语材料的翻译与核验

评注使用德、日、英、法、意等语种材料时，翻译质量直接决定结论可信度。本协议把“翻译”当作证据处理，而不是当作文字改写。原则：**法义准确与可追溯优先于文采；翻译不能替代原文核验**。

## 一、什么时候需要翻译

- 引用外国法条、判例、评注原文并据以形成论证；
- 用外语文献检验中国法解释方案；
- 需要向中文读者呈现外语材料的精确表述。

仅用于定位线索的二手中文介绍，不必进入翻译流程，但不得作为外国法现状的唯一依据。决定结论的术语必须对照原文；原文无法取得时，缩小主张并标注转引。

## 二、五阶段流程

### 1. 解析与分块

- PDF/扫描件先转结构化文本；保留条号、边码（Randnummer）、脚注锚点与分栏结构；
- 按段落、条文、判决理由段落切块，不按固定字数硬切；
- 每块分配稳定块 ID 并记录源文哈希，便于复用与回溯。

### 2. 术语预检

- 先查项目术语表、个人术语表、已核验译法，再查词典，最后才依语境推断；
- 仅把命中的词条注入请求，不把整部术语表塞进上下文；
- 未收录术语采用“推衍译名＋首次出现附原文”，并登记待确认；
- 同一概念同一译名；一词多义按法域、部门法、年代与概念义消歧，不追求机械唯一。

术语优先级：项目术语表 > 个人术语表 > 已核验纠错 > 内置词典 > 语境推断。低置信度或标为待复核的词条必须结合上下文复核，不得让低质量词条压倒明确语境。

### 3. 翻译执行

- 第一轮保留法律结构：主体、行为、客体、条件、例外、时间、指代与法律后果；
- 第二轮处理中文句法与学术语气，不得改变法律含义；
- 长难句先拆主句从句关系，再重组，不按原文语序直译；
- 段落级优于句级；能力较强的模型可附前 1–2 句原文与译文作上下文，能力较弱的模型不硬塞长上下文；
- 批量材料对源文哈希去重，未变更段落复用旧译。

### 4. 自动校验（机器可判）

- 术语命中率：对照术语表，低于阈值即重译；
- 法条与判例引证完整性：条号、款项、案号、边码、日期、数字逐项比对；
- 占位符与编号：脚注锚点、交叉引用、公式符号计数一致；
- 长度比异常：显著偏离均值者标记为漏译或增译嫌疑；
- 条号连续性与双语对齐（法典、判决类材料）。

### 5. 人工闸门与迭代

- 自动校验不通过：先升级模型重试一次，仍不通过转人工；
- 法条译法、法律关系、程序动作、引证出处必须由具备双语能力者终审；
- 新术语经确认后入库，并把语境触发规则写回术语表；
- 翻译稿与原文、术语账、校验报告一并留存，供审稿质询。

## 三、法学翻译硬约束

- 区分义务、禁止、权限、裁量、努力义务、推定与法律拟制；“应当”“可以”“不得”“视为”“推定”不得互代；
- 区分 `又は/若しくは`、`及び/並びに`、`oder/und`、`or/and` 的逻辑层级，不用中文顿号抹平选择与并列结构；
- 保留条、款、项、号、案件号、日期、数量、公式、交叉引用、引号范围与脚注锚点；
- 判决区分法院陈述、当事人主张、引用先例与作者评论；
- 论文保留引证立场及“可能、通常、未必”等限定，不把不确定表述强化为结论；
- 民法等法律修改时，按文献时点识别旧法/现行法概念，不得用现行法概念回译旧法文献；
- 译文中的法条现行有效性另行核验，翻译正确不等于规范有效。

## 四、四层记忆

1. **文档胶囊**：全书主题、核心概念、术语决策摘要；
2. **章节摘要**：本章论点、关键术语、引证网络；
3. **邻接语境**：前文原文与译文、当前段落结构；
4. **术语决策账**：术语、译法、法域、年代、置信度、变更记录。

## 五、四层质检

1. **语义**：法义准确、逻辑连贯、论证完整；
2. **术语**：一致性、法域适配、年代准确；
3. **结构**：段落完整、条号连续、脚注锚点齐备；
4. **版面**：字体字号、行距缩进、表格与双语栏对齐。

## 六、交付形态

按用途切换，不得混用：

- `Clean`：仅净译文，供内部快速阅读；
- `Annotated`：净译文＋高风险选择与待确认项标注；
- `Bilingual Review`：逐句对照，供审校与引注核验。

对外发表、合同、正式法律文书不得“机翻即发”；关键文档适用全人工译后编辑与第二人独立复审的通行标准。

## 七、与评注流程的接口

- 翻译产物进入 `03-source-ledger.jsonl`，`source_form` 标注为译本并记录原文来源；
- 术语账并入项目的术语决策记录，与中文术语保持一致；
- 译文不得直接充当“外国法现状”的证据；结论仍以原文核验为准（见 [比较法协议](comparative-law.md)）。
